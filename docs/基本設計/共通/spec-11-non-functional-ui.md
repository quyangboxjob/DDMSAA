# 11 非機能要件

## 1. セキュリティ

| 項目 | 決定 |
|---|---|
| 認証 | `login_id` + BCrypt パスワード、HttpOnly セッション Cookie |
| 認可 | ADMIN / EMPLOYEE / CUSTOMER とサーバー側の顧客スコープ |
| 通信 | 本番は HTTPS 必須 |
| CSRF | Cookie 認証の変更系 API で必須 |
| 添付 | MIME と拡張子を検証、10 MiB 以下、スキャン完了まで配信禁止 |
| 監査 | ログイン、権限拒否、状態変更、出力、添付アクセスを記録 |
| 秘密情報 | Git・ログ・画面・監査詳細へ保存しない |

## 2. 性能と容量

| 項目 | 初版基準 |
|---|---|
| 通常 API | 95 パーセンタイル 2 秒以内（通常検索） |
| 同期 CSV | 10,000 件以下 |
| 非同期 CSV | 10,001 件以上は `export_jobs` で生成 |
| 出力物の保持 | 24 時間で失効 |
| 添付 | 1 ファイル 10 MiB、注文あたり合計 50 MiB |
| 可用性 | 業務時間内の計画保守を除き月間 99.5% を目標 |

## 3. 運用

- DB は日次バックアップ、四半期ごとに復元試験を行う。
- 監査ログは削除・改ざん不可の保管領域へ定期退避する。
- 重大な送信失敗、スキャン失敗、出力失敗は管理者向け監視対象とする。
- タイムゾーンは Asia/Tokyo、日時保存は `timestamptz`、画面表示は日本時間とする。
