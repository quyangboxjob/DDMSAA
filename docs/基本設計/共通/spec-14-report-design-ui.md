## 3. 共通出力方針

| 項目 | 方針 |
|------|------|
| ファイル名規則 | `spec-00-doc-standard-ui.md` §2「出力ファイル」（正本）に従う。帳票固有の規則がある場合のみ §2 の帳票別設計に記載する |
