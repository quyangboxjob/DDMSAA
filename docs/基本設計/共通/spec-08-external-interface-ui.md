# 08 外部インタフェース設計

## 1. 外部連携一覧

| ID | 連携先 | 方向 | 用途 | 失敗時 |
|---|---|---|---|---|
| IF-01 | SMTP/メールサービス | 出力 | 承認依頼、承認/差戻し、取消し、出力完了通知 | `notification_logs` に記録し再試行 |
| IF-02 | S3 互換オブジェクトストレージ | 双方向 | 添付、PDF、CSV の暗号化保管 | API は失敗を返し、孤立ファイルを清掃 |
| IF-03 | マルウェアスキャン | 出力/照会 | 添付を `PENDING` から `SAFE` / `REJECTED` に更新 | `PENDING` のまま配信しない |

メールは認証に使用しない。外部サービスの認証情報、バケット名、SMTP 秘密値は環境変数または Secret Manager だけで保持する。

## 2. 通知イベント

| イベント | 宛先 |
|---|---|
| 承認申請 | 承認対象の ADMIN |
| 承認/差戻し | 注文作成者と担当社員 |
| 注文取消し | 注文作成者、担当社員、顧客の有効な通知先 |
| CSV/PDF 完成 | 出力を依頼した利用者 |

送信失敗は指数バックオフで 3 回まで再試行し、最終失敗を `notification_logs` と監査に残す。
