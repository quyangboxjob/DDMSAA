# 08 外部インタフェース設計

> 外部システム・サービスとの連携：メール（認証 Magic Link・通知）、ファイルストレージ、ファイル出力（Excel/ZIP）、サードパーティ API など。
> インタフェースごとに下記のテンプレートを複製して記入する。

（文書ヘッダは `spec-00-doc-standard-ui.md` を参照）

---

## 1. 外部インタフェース一覧

| IF ID | 名称 | 方向 | 連携先 | トリガー | 関連機能 |
|--------|------|------|---------|------|---------|
| IF-01 | メール送信 | 出力 | SMTP/メールサービス | 認証（Magic Link）・申請通知・エスカレーション | F-* |
| IF-02 | ファイルストレージ | 双方向 | ファイルストレージボリューム | 画像資料の保存・読込 | F-REQ-* |
| IF-03 | Excel 出力 | 出力 | ファイルダウンロード | 帳票 | F-RPT-* |
| {{ … }} | | | | | |

> 方向：出力（システム→外部）/ 入力（外部→システム）/ 双方向。

## 4. ファイル出力規約（帳票/エクスポートがある場合）

| 出力ID | 内容 | フォーマット | ファイル名規則 | トリガー |
|--------|------|------|-----------|------|

| OUT-02 | 情報確認票（複数名） | zip（xlsx を格納） | `確認票_ユーザID_氏名_YYYYMMDD.xlsx` | F-RPT-02 |
| {{ … }} | | | | |

### 記入要領

- 外部依存には必ず**失敗時の処理**（リトライ・アラート・補償）を定義し、外部が常に成功すると仮定しない。
- メール内容に個人情報が含まれる場合は、マスキングとコンプライアンスに留意する。
- ファイル名規則は `spec-07-api-list-ui.md` と整合させる。
