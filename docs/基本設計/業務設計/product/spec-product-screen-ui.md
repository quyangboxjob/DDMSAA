# 画面基本設計 — 商品管理

> 対象画面：SCR-09 商品一覧 / SCR-10 商品登録/編集
> 画面 ID・パス・ロールの正本は `共通/spec-screen-list-ui.md`、共通 UI は `共通/spec-12-screen-common-ui.md`。業務ルールは `spec-product-business-ui.md`、権限は `共通/spec-03-auth-ui.md`。

## 1. SCR-09 商品一覧

| 項目 | 内容 |
|---|---|
| パス | `/products` |
| 利用ロール | ADMIN、EMPLOYEE（参照のみ） |
| 利用 API | `listProducts`、`updateProductStatus`（ADMIN） |
| 遷移 | 行選択 → SCR-10 / 新規（ADMIN）→ SCR-10 |

```mermaid
flowchart TB
  subgraph P[商品一覧]
    subgraph S[検索条件]
      S1[キーワード 商品コード・商品名]
      S2[カテゴリ]
      S3[税区分]
      S4[状態]
    end
    A[新規登録 ADMIN のみ]
    subgraph T[テーブル]
      TH[商品コード / 商品名 / カテゴリ / 標準単価 / 税区分 / 状態 / 操作]
    end
    PG[ページング]
  end
  S --> A --> T --> PG
```

| 区分 | 項目 | 内容 |
|---|---|---|
| 検索条件 | キーワード | 商品コード・商品名の部分一致 |
| 検索条件 | カテゴリ、税区分、状態 | 税区分は STANDARD(10%) / REDUCED(8%) / EXEMPT(0%)。表示は日本語名 |
| 一覧列 | 商品コード、商品名、カテゴリ、標準単価（円・桁区切り）、税区分、状態 | 既定の並び：商品コード昇順 |
| 行操作 | 有効化/無効化（ADMIN のみ） | 無効化は確認ダイアログ → `updateProductStatus` |

- EMPLOYEE には「新規登録」と状態切替を表示しない。
- 無効商品は注文登録の商品選択に出ない（SCR-12）。

## 2. SCR-10 商品登録/編集

| 項目 | 内容 |
|---|---|
| パス | `/products/new`、`/products/:productId/edit` |
| 利用ロール | ADMIN（登録・編集）、EMPLOYEE（参照のみ。全項目を読み取り専用で表示し、保存ボタンを出さない） |
| 利用 API | `createProduct`、`getProduct`、`updateProduct` |

```mermaid
flowchart TB
  subgraph P[商品登録/編集]
    F1[商品コード]
    F2[商品名]
    F3[カテゴリ]
    F4[標準単価]
    F5[税区分]
    F6[状態 編集のみ]
    B[保存 / キャンセル]
  end
  F1 --> F2 --> F3 --> F4 --> F5 --> F6 --> B
```

| 項目 | 部品 | 必須 | 制約 | 備考 |
|---|---|:---:|---|---|
| 商品コード | テキスト | ○ | 最大 50、重複不可 | 編集時は変更不可 |
| 商品名 | テキスト | ○ | 最大 200 | |
| カテゴリ | テキスト | — | 最大 100 | |
| 標準単価 | 数値 | ○ | 0 以上、小数 2 桁、最大 15 桁 | 円 |
| 税区分 | 選択 | ○ | STANDARD / REDUCED / EXEMPT | 税率は表示のみ（10% / 8% / 0%） |
| 状態 | 選択 | 編集 ○ | 有効 / 無効 | |

| 操作 | 処理 | メッセージ |
|---|---|---|
| 保存（新規） | `createProduct` | 成功 `I0010`、商品コード重複 `E0007`、入力誤り `E0008`/`E0030`〜`E0034` |
| 保存（編集） | `updateProduct` | 成功 `I0011` |
| キャンセル | 入力があれば確認 | `W0011` |

- 画面に「既存注文は変更されない」旨の注記を表示する（業務設計 §3：注文明細は商品情報を複写する）。文言は`I0030`。
