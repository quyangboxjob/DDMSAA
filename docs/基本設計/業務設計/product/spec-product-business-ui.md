# 業務基本設計 — 商品管理

## 1. 権限

商品を作成、更新、有効化/無効化できるのは ADMIN だけである。EMPLOYEE は有効商品を参照できる。CUSTOMER は注文明細に記録された商品情報だけを参照でき、商品 API は利用しない。無効商品は新規注文で選択できない。

## 2. 管理項目

商品コード（重複不可）、商品名、カテゴリ、標準単価（0 以上）、税区分（STANDARD/REDUCED/EXEMPT）、有効状態を管理する。

## 3. 注文との関係

注文作成時に商品コード、名称、単価、税区分、税率を明細へ複写する。後から商品を変更・無効化しても、既存注文の内容や税額は変わらない。
