# 業務基本設計 — 顧客管理

## 1. 権限

顧客、顧客連絡先、担当社員の管理は ADMIN だけが行う。EMPLOYEE は有効な担当割当を持つ顧客だけを参照し、その顧客の注文を操作できる。CUSTOMER は自社の情報と注文だけを参照する。

## 2. 管理項目

顧客コード（重複不可）、顧客名、メール、電話、有効状態、通知先連絡先、担当 EMPLOYEE を管理する。顧客利用者は `users.customer_id` と必ず紐付ける。

## 3. 無効化

無効顧客は新規注文の対象にできない。既存注文・履歴・監査は保持し、物理削除しない。
