# 業務基本設計 — 注文添付

## 1. 利用者と操作

ADMIN は全注文、EMPLOYEE は担当注文だけに添付をアップロード・削除できる。CUSTOMER は自顧客注文の `CUSTOMER` 公開かつ `SAFE` の添付だけを閲覧・ダウンロードできる。

## 2. 保存規則

| 項目 | 初版決定 |
|---|---|
| 許可形式 | PDF、DOCX、XLSX、CSV、PNG、JPG/JPEG |
| 最大サイズ | 1 ファイル 10 MiB、注文合計 50 MiB |
| 検証 | 拡張子と MIME を両方確認する |
| スキャン | 保存直後は PENDING。SAFE だけ配信し、REJECTED は配信しない |
| 公開範囲 | INTERNAL 又は CUSTOMER をアップロード者が指定する |
| 保持期間 | アップロード後 365 日 |

## 3. 処理

アップロード成功はファイル保存の完了であり、ダウンロード可能を意味しない。スキャン完了後にだけダウンロードリンクを有効化する。ダウンロード時にも注文、顧客、公開範囲、スキャン状態を再検証し、ストレージの恒久 URL を利用者へ返さない。

## 画面

添付は独立画面を持たず、注文詳細（SCR-13）の添付パネルとアップロードダイアログ（SCR-13/DLG-4）で提供する。設計は `../order/spec-order-screen-ui.md` §3.3。
