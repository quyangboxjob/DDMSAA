# 業務基本設計 — ユーザー管理

## 1. 権限

ADMIN だけがユーザーを作成、更新、無効化、ロール変更できる。ロールは ADMIN、EMPLOYEE、CUSTOMER の 3 種だけである。

## 2. 管理項目

ログイン ID、表示名、メールアドレス、ロール、有効状態、CUSTOMER の顧客紐付けを管理する。パスワードは BCrypt ハッシュとしてだけ保存し、画面・CSV・ログ・監査に平文を残さない。

## 3. 無効化

無効化時は有効なセッションを失効させる。既存注文・承認・監査の操作者情報は保持するため、物理削除しない。
