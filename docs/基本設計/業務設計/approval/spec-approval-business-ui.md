# 業務基本設計 — 承認管理

## 1. 初版の承認経路

初版は、注文金額にかかわらず ADMIN による 1 段承認とする。ADMIN が後から経路マスタを更新できるが、変更は新しい申請だけに適用する。

## 2. 処理

1. ADMIN 又は担当 EMPLOYEE が DRAFT/RETURNED 注文を申請する。
2. システムは有効な承認経路を注文にスナップショット保存し、状態を PENDING_APPROVAL にする。
3. 割り当てられた ADMIN が承認又は理由付き差戻しを行う。
4. 最終承認で APPROVED、差戻しで RETURNED に遷移する。
5. 操作履歴、通知ジョブ、監査ログを保存する。

## 3. 制約

- 承認/差戻しは割り当てられた ADMIN 本人だけが実行できる。
- 差戻し理由は 1～500 文字必須。
- 代理承認、多段承認、金額別経路は初版では実装しない。ただしテーブル構造は将来の追加を妨げない。
- 承認待ち中の注文は編集・取消し不可。
