# 業務基本設計 — 帳票・集計

## 1. 提供物

| 機能 | ADMIN | EMPLOYEE | CUSTOMER |
|---|:---:|:---:|:---:|
| 注文 PDF | 全件 | 担当顧客 | 自社注文のみ |
| 注文/顧客/商品集計 | 全件 | 担当顧客 | × |
| CSV 出力 | 全件 | 担当顧客 | × |

## 2. 出力仕様

- 注文 PDF は A4 日本語レイアウトで、注文番号、顧客、明細、税額、合計、状態を出す。対象は APPROVED の注文に限る（`downloadOrderPdf`）。
- CSV は注文単位（1 行 = 1 注文）で、UTF-8 BOM、ファイル名は `orders_YYYYMMDD.csv`。列は注文番号、注文日、顧客コード、顧客名、状態、担当者、小計、税額、合計の順とする（`spec-report-screen-ui.md` §1.3）。対象は SCR-16 の共通の絞り込み条件（期間・顧客・状態）に合う注文で、件数は注文の件数とする。
- CSV は常に `export_jobs` で依頼し、すべての出力を記録する。10,000 件以下は依頼時に同期生成して READY で返し、10,001 件以上は QUEUED として非同期生成する（`createExportJob`。BR-RPT-002）。
- 出力ジョブは、ADMIN はすべての利用者の分、EMPLOYEE は自分が依頼した分だけを参照・ダウンロードできる（BR-RPT-003）。
- 出力成果物は作成完了から 24 時間で失効し、ダウンロード時に再認可する。

## 3. 集計の正しさ

集計・CSV・PDF には利用者のデータ範囲を必ず適用する。承認済み、取消しを含むかなどの状態条件はリクエストと出力メタデータに明示する。

## 画面

SCR-16 の画面設計は `spec-report-screen-ui.md`。注文 PDF の出力は注文詳細（SCR-13）から行う。
