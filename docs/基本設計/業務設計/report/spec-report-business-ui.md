# 業務基本設計 — 帳票・集計

## 1. 提供物

| 機能 | ADMIN | EMPLOYEE | CUSTOMER |
|---|:---:|:---:|:---:|
| 注文 PDF | 全件 | 担当顧客 | 自社注文のみ |
| 注文/顧客/商品集計 | 全件 | 担当顧客 | × |
| CSV 出力 | 全件 | 担当顧客 | × |

## 2. 出力仕様

- 注文 PDF は A4 日本語レイアウトで、注文番号、顧客、明細、税額、合計、状態を出す。
- CSV は UTF-8 BOM、列順は API 定義に従う。
- 10,000 件以下は同期作成、10,001 件以上は `export_jobs` で非同期作成する。
- 出力成果物は作成完了から 24 時間で失効し、ダウンロード時に再認可する。

## 3. 集計の正しさ

集計・CSV・PDF には利用者のデータ範囲を必ず適用する。承認済み、取消しを含むかなどの状態条件はリクエストと出力メタデータに明示する。
