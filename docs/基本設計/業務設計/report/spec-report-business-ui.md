| 項目 | 内容 |
| --- | --- |

| 対象モジュール | M-RPT 検索・帳票・報表 |
| 版数 | 0.1（初稿） |
| 作成日 | 2026-10-13 |
| ステータス | レビュー待ち |

## 2. 目的・範囲

権限範囲内の注文検索、注文書・注文確認書の出力、受注件数・金額・顧客別・商品別の集計、および CSV 出力を提供する。顧客は自社注文の検索・閲覧に限定する。

## 3. 関連画面一覧

| 画面 ID | 画面名 | 主な利用者 | 主な機能 |
| --- | --- | --- | --- |
| SCR-RPT-01 | 注文検索 | 管理者、一般社員、顧客 | 条件検索、並び替え、ページング、詳細遷移。一般社員は自分の注文、顧客は自社注文に限定する。 |
| SCR-RPT-02 | 受注集計 | 管理者、一般社員 | 期間、顧客、商品別の件数・金額を集計する。一般社員は自分の注文に限定する。 |
| SCR-RPT-03 | CSV 出力 | 管理者、一般社員 | 検索・集計結果を CSV として出力する。一般社員は自分の注文に限定する。 |
| SCR-RPT-04 | 注文書出力 | 権限保有者 | 承認済み注文の注文書または注文確認書を出力する。 |

## 4. 検索・集計ルール

- 注文検索条件は、注文番号、顧客、注文日範囲、ステータス、担当社員、金額範囲を基本とする。
- 顧客の検索結果は常に自社注文だけとする。画面条件の改変や URL 直接指定では範囲を広げられない。
- 管理者は全注文を検索・集計できる。
- 一般社員の検索・集計・CSV 出力範囲は `sales_user_id` が本人である注文だけとする。顧客は自社注文の検索・帳票出力だけとし、集計・CSV 出力はできない。
- CSV は画面で許可された検索結果と同じ権限条件を適用する。CSV 出力操作を監査ログに記録する。
- 帳票出力対象は承認済み注文とする。正式レイアウトと PDF の要否は未確定とする。

## 5. 主なデータ・集計項目

| 帳票・集計 | 主な項目 | 対象 |
| --- | --- | --- |
| 注文一覧 | 注文番号、顧客、担当者、注文日、状態、合計金額 | 権限範囲の注文 |
| 受注件数・金額 | 期間内の注文数、合計金額、承認済み件数 | 管理者、一般社員 |
| 顧客別集計 | 顧客コード、顧客名、件数、合計金額 | 管理者、一般社員 |
| 商品別集計 | 商品コード、商品名、数量、金額 | 管理者、一般社員 |
| 注文書 | 注文番号、顧客、明細、金額、承認情報 | 承認済み注文 |

## 6. API 概要

| メソッド | パス | 権限 | 内容 |
| --- | --- | --- | --- |
| GET | `/api/orders` | 認証済み | 管理者は全件、一般社員は自分の注文、顧客は自社注文だけを検索する。 |
| GET | `/api/reports/orders/summary` | 管理者、一般社員 | 一般社員は自分の注文だけを集計する。 |
| GET | `/api/reports/customers` | 管理者、一般社員 | 一般社員は自分の注文だけを顧客別に集計する。 |
| GET | `/api/reports/products` | 管理者、一般社員 | 一般社員は自分の注文だけを商品別に集計する。 |
| GET | `/api/orders/export.csv` | 管理者、一般社員 | 一般社員は自分の注文だけを CSV 出力する。 |
| GET | `/api/orders/{orderId}/document` | 権限保有者 | 承認済み注文の帳票を出力する。 |

## 7. 非機能・運用

- 一覧検索および詳細表示は通常業務ネットワークで概ね 3 秒以内を目標とする。
- 大量 CSV・帳票出力は同期応答時間を超える場合、非同期処理または進捗表示を検討する。
- CSV の文字コード、列順、個人情報のマスキング要否は帳票仕様で確定する。
